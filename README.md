# Fluttershy Unity Fan Demo

This repo contains a small Unity 3D starter demo inspired by Fluttershy.

Important:
- This is an original fan-made project.
- It does not ship copyrighted character models, artwork, or music.
- You need Unity 2022.3 LTS to open and run it.

## How to run
1. Install Unity Hub and Unity 2022.3 LTS.
2. Download or clone this repo.
3. Open the folder in Unity Hub as a project.
4. Open `Assets/Scenes/Main.unity` and press Play.

## Controls
- `WASD` / Arrow keys: move
- Mouse: look around
- `Esc`: unlock cursor

## Play link
There is no hosted web playable build yet. To play it, open the project in Unity.
