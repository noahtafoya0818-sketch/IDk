# Fluttershy Unity Fan Demo

A tiny, original, fan-made Unity 3D starter demo inspired by Fluttershy. It uses only Unity primitives and does **not** include copyrighted My Little Pony character or music assets.

## Open it

1. Install Unity Hub and Unity **2022.3 LTS**.
2. Add this repository's downloaded ZIP as a project.
3. Open the project in Unity Hub.
4. Open `Assets/Scenes/Main.unity` and press **Play**.

## Controls

- **WASD** or arrow keys: move
- **Mouse**: look around
- **Escape**: unlock the mouse

## Download

Use GitHub's **Code → Download ZIP** button on this repository. A standalone Windows/macOS/WebGL build is not included yet because Unity builds must be generated by Unity on a build machine.

## Character assets

If you own or have permission to use a Fluttershy model, place it in `Assets/Art/` and replace the placeholder object in the scene. Do not redistribute third-party assets without permission.
